# 🚀 24/7 Autonomous SEO & Social Media Agent for GPT-TYPE (`gpttype.blogspot.com`)

This guide explains how to activate your autonomous AI agent hosted **100% FREE on GitHub Actions**. The agent runs every 12 hours (or on demand), performs keyword research, generates high-ranking SEO blog posts with structured Schema markup and interactive typing exercises, publishes directly to `gpttype.blogspot.com`, and broadcasts across social media.

---

## 🌟 How the Agent Propels GPT-TYPE to #1 on Google

1. **Interactive Dwell Time Boosters**: Every article includes an interactive typing drill card with direct links to `https://gpttype.blogspot.com` speed tests. Readers practice right on your site, keeping dwell times above 3 minutes—a major Google ranking signal.
2. **Topical Authority Clustering**: The agent targets 6 high-intent keyword clusters (Speed Boosters, Programming Typing, Job/Exam Prep, 120+ Languages, Ergonomics, and Beginners).
3. **Google Rich Snippets (Schema.org)**: Every post includes automated JSON-LD `FAQPage` schemas, allowing Google to display expanded question cards directly in search results.
4. **Autonomous Memory**: `data/post_history.json` tracks what was published, preventing duplicate topics and rotating clusters evenly.

## 📋 Step 2: Set Up Google Blogger API Credentials (3 Minutes)

To allow the agent to publish posts automatically to `gpttype.blogspot.com`:

1. Go to **[Google Cloud Console](https://console.cloud.google.com/)**.
2. Click the project dropdown at the top and click **NEW PROJECT** (name it `GPT-TYPE-Agent`).
3. In the search bar at the top, search for **Blogger API v3** and click **ENABLE**.
4. In the left menu, go to **APIs & Services ➔ OAuth consent screen**:
   - Select **External** and click **CREATE**.
   - App name: `GPT-TYPE Agent`
   - User support email: Select your email.
   - Developer contact email: Enter your email.
   - Click **SAVE AND CONTINUE** through Scopes.
   - In **Test users**, click **ADD USERS** and add your own Google email address (the one that owns the blog). Click **SAVE AND CONTINUE**.
5. In the left menu, go to **APIs & Services ➔ Credentials**:
   - Click **+ CREATE CREDENTIALS** ➔ **OAuth client ID**.
   - Application type: **Desktop app**.
   - Name: `GPT-TYPE Desktop Client`.
   - Click **CREATE**.
   - Copy your **Client ID** and **Client Secret**.

---

## 📋 Step 3: Run the 1-Click Blogger Auth Script

On your computer terminal in `f:\blogger web`:

```bash
python setup_blogger_auth.py
```

1. Enter your **OAuth Client ID** and **Client Secret**.
2. A browser window opens—sign in with your Google account and click **Continue / Allow**.
3. The script will instantly print:
   - `BLOGGER_REFRESH_TOKEN`
   - `BLOG_ID` (the numeric ID for `gpttype.blogspot.com`)

## 📋 Step 4: (Optional) Set Up Free Telegram Alerts to Your Phone

Get an instant notification whenever the agent publishes an article:
1. Open Telegram and search for **`@BotFather`**.
2. Send `/newbot`, choose a name, and copy the **HTTP API Token** (`TELEGRAM_BOT_TOKEN`).
3. Search for **`@userinfobot`** and send `/start` to see your numeric ID (`TELEGRAM_CHAT_ID`).

## 📋 Step 5: Push Your Code to GitHub & Add Secrets

1. Initialize git and push this folder to a new **private or public GitHub repository**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of 24/7 GPT-TYPE autonomous agent"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/gpt-type-agent.git
   git push -u origin main
   ```

2. Open your repository on GitHub:
   - Go to **Settings** ➔ **Secrets and variables** ➔ **Actions**.
   - Click **New repository secret** and add:

| Secret Name | Description | Required? |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | Your Google AI Studio API key | ✅ Yes |
| `BLOGGER_CLIENT_ID` | OAuth Client ID from Google Cloud | ✅ Yes |
| `BLOGGER_CLIENT_SECRET` | OAuth Client Secret from Google Cloud | ✅ Yes |
| `BLOGGER_REFRESH_TOKEN` | Generated by `setup_blogger_auth.py` | ✅ Yes |
| `BLOG_ID` | Numeric Blog ID from Blogger dashboard | ✅ Yes |
| `BLOG_URL` | `https://gpttype.blogspot.com` | Optional (default set) |
| `TELEGRAM_BOT_TOKEN` | Bot token from @BotFather | Optional (for alerts) |
| `TELEGRAM_CHAT_ID` | Your Telegram ID from @userinfobot | Optional (for alerts) |
| `TWITTER_API_KEY` / `SECRET` | X / Twitter developer tokens | Optional |
| `FACEBOOK_PAGE_ACCESS_TOKEN`| Facebook Page token | Optional |

---

## 📋 Step 6: Test & Verify

1. In your GitHub repository, click the **Actions** tab.
2. Select **GPT-TYPE 24/7 Autonomous SEO Agent** in the left sidebar.
3. Click **Run workflow**:
   - Check `Simulate run without publishing (Dry Run)` if you want to test without touching your blog, or leave unchecked to publish live!
   - Click **Run workflow**.

From now on, GitHub Actions will automatically trigger every 12 hours (at 06:00 and 18:00 UTC), post fresh high-ranking content, and update its memory automatically!
